# Optimal Asset Replacement Model

**Dynamic programming · Infrastructure planning · Decision-making under uncertainty**

This project develops a quantitative framework for the **optimal replacement of long-lived physical assets**, motivated by capital-planning problems in institutional infrastructure.

The broader objective is to determine when an asset should be maintained, retained, or replaced when future operating costs, failures, and replacement expenditures are uncertain.

## Economic Problem

Capital assets generate services over many periods, but maintenance costs and failure risks generally rise with age.

The decision problem is therefore intertemporal:

> **When does the expected future cost of keeping an existing asset exceed the value of replacing it?**

## Modelling Framework

The project is built around dynamic optimization and asset-management methods, including:

- dynamic programming;
- state-dependent operating and maintenance costs;
- transition probabilities;
- replacement decisions;
- uncertainty in future asset conditions and expenditures;
- capital-budget planning.

The repository also explores a dynamic discrete-choice formulation inspired by **Rust (1987)**, including value-function iteration and nested fixed-point concepts.

## Applied Context

The project originates from work on quantitative methodologies for **capital asset management and infrastructure planning**, including long-term replacement strategies, maintenance costs, budgeting, and decision-making under uncertainty.
